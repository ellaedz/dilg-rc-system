═══════════════════════════════════════════════════════════════════
  🎯 HOW IT WORKS
═══════════════════════════════════════════════════════════════════

1. Citizen submits report with GPS (lat, lon)
2. System loads public/gis/boundary.geojson
3. Point-in-polygon algorithm checks each barangay boundary
4. System finds matching barangay
5. Report auto-assigned to that barangay
6. Citizen receives Tracking ID
7. Report appears in barangay dashboard

⚠️ COORDINATE ORDER:
→ Mobile GPS sends: [latitude, longitude]
→ GeoJSON stores: [longitude, latitude]
→ System handles conversion automatically!

═══════════════════════════════════════════════════════════════════
  🔍 POINT-IN-POLYGON ALGORITHM
═══════════════════════════════════════════════════════════════════

Algorithm: Ray Casting
1. Cast ray from point to infinity
2. Count edge crossings
3. ODD crossings = INSIDE
4. EVEN crossings = OUTSIDE

Supports:
✅ Polygon
✅ MultiPolygon
✅ FeatureCollection

Barangay Name Properties:
✅ name, Name, NAME
✅ barangay, Barangay, BARANGAY
✅ brgy, Brgy, BRGY
✅ BGY_NAME, BRGY_NAME
✅ ADM4_EN, NAME_4

═══════════════════════════════════════════════════════════════════
  ⚠️ ERROR HANDLING
═══════════════════════════════════════════════════════════════════

Case 1: GPS Missing
→ "Location Not Available"
→ Report still submitted, needs manual review

Case 2: Outside Santa Cruz
→ "Outside Santa Cruz Coverage"
→ Report forwarded to DILG for review

Case 3: GeoJSON Missing
→ Falls back to config bounding boxes
→ If fallback fails: "Barangay Detection Unavailable"
